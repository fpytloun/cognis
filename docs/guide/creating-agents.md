# Creating Agents

Open **Agents → New** to create an agent.

## Key sections

### Identity

- agent ID
- name / display name
- description
- avatar URL

### Personality

- tone
- temperament
- purpose
- behavioral rules
- system prompt

### Tools and permissions

- allowed secrets
- delegation permission
- max delegation depth
- per-tool permission policy

### MCP servers

Agents can define local MCP servers with:

- name
- command
- arguments
- environment variables
- timeout

Use the agent editor to test configured MCP servers after saving the agent.

### LLM configuration

- provider selection
- model override
- temperature
- max tokens

### Workflow settings

- available workflows
- default workflow
- selection mode
- step agent overrides
