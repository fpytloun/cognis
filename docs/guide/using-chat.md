# Using Chat

## Starting a conversation

Open **Chat → New** and select an agent.

## What the UI shows

- streaming assistant responses
- tool call indicators
- delegation status updates
- queued-message indicators
- reconnect status for the WebSocket connection

## First-run readiness

Admins may see a setup banner or **Getting started** guide until:

- Mnemory is reachable
- Intaris is reachable
- an LLM provider is configured
- at least one agent exists

## Recovery and diagnostics

Use **Settings → System** for:

- provider health
- readiness checks
- migration/version details
- safe runtime configuration summary
