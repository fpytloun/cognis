# Product showcase

Cognis is not only a place to chat with agents. It is a workspace for real
work. Agents can research, edit files, run commands, use browsers, coordinate
other sessions, and produce durable results.

The same work remains visible at your desk, at home, or on your phone. The
examples below use Lumen, a fictional lighting company, in the Porcelain Light
appearance. Its conversations, code changes and costs are seeded demo data;
replies that stream live come from a local mock model.

## Start from the dashboard

The dashboard shows your agents, upcoming schedules, recently finished tasks
and the conversations waiting for you.

![Dashboard with agents, schedules, tasks and conversations](../assets/screenshots/dashboard.webp)

Press **Ctrl+K** (or **⌘K**) to search tasks, schedules, conversations and
documents from anywhere.

![Command palette search results](../assets/screenshots/command-palette.webp)

## Keep agents one click away

Pin a conversation and its agent stays at the right edge of every page. Click
the avatars to spread them, pick an agent and continue in a compact chat. Each
agent keeps its main conversation and pinned topics as tabs. See
[Pinned conversations](projects.md#pinned-conversations).

![Pinned agent avatars and a compact chat over the Library](../assets/screenshots/pinned-chats.webp)

![Opening pinned agents from any page and switching between them](../assets/screenshots/pinned-chats.gif)

The [macOS app](macos-companion.md) shows the same pins as floating agent
icons on the desktop, over any application and with the main window closed.

## Inspect work

The conversation timeline reports exploration, file edits, commands,
delegation and system notices as they occur. The activity sidebar connects
those events to the complete work graph.

![Conversation with its activity overview](../assets/screenshots/desktop-workspace.webp)

The **Work** view groups files, commands, mutations, artifacts and
deliverables. Each command keeps its description, status, duration and output.

![Changed-file navigation and statistics](../assets/screenshots/work-file-navigation.png)

![Command history and output](../assets/screenshots/desktop-work-commands.webp)

Changed files remain inspectable beside the conversation. You can review the
exact diff without leaving the workspace.

![Conversation beside a Work source diff](../assets/screenshots/desktop-work-diff.webp)

![Expanded source diff](../assets/screenshots/work-expanded-diff.png)

## Track usage and cost

Usage shows cost and tokens by day, provider, model, agent, project and
conversation.

![Usage overview](../assets/screenshots/usage-overview.webp)

The cost flow follows spend from a project to its agents and the
conversations and tasks behind it. Click a day to drill into it, then click a
node to filter.

![Cost flow by project, agent and conversation](../assets/screenshots/usage-flow.webp)

![Drilling from an expensive day into the cost flow](../assets/screenshots/usage-drilldown.gif)
